# Funniest One-Line Out-of-Office Reply

Entry for the make.fun bounty "Funniest One-Line Out-of-Office Reply"
(`u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8`).

## What it does

`main.py` writes a single out-of-office email auto-reply — one line, under
160 characters — to `/output/entry.txt`. The text is fixed and original,
written for this bounty: a real away message with a fresh turn on the usual
"my inbox is being handled while I'm away" line.

## How to run

```sh
python3 main.py
```

The program writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if that
environment variable is set, which is handy for local testing). It uses only
the Python standard library, needs no network access, and is deterministic:
every run writes byte-identical output.
